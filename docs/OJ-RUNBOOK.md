# Verilog OJ 工作流

OJ 入口：`http://10.245.130.66/oj/`。只在可信校园网络和使用者本人可见登录会话中操作。

## 读路径

1. 打开当前题目，记录题号、顶层 module、端口、语言版本和时限。
2. 保存题面提供的模板；不要凭历史题号假设接口未变。
3. 在本地编译并用独立参考模型测试。
4. 提交前重新读取题号和编辑器内容，确认没有跨题粘贴。
5. 提交后读取提交记录，保存判定、提交号和平台生成的综合证据。

## 写入门槛

一次提交必须同时具备：

- 使用者明确指定当前题目；
- 本地编译/测试通过；
- 页面顶层接口与源文件一致；
- 使用者对这一次提交明确确认。

提交结果超时、断线或返回 5xx 时属于**结果未知**。先读取提交历史；若平台已经生成记录，禁止自动重试。历史 Accepted 也不是对新代码或新题目的提交授权。

## 证据解释

- `iverilog/vvp` 通过：本地验证通过。
- OJ `Accepted`：平台对该次提交判定通过。
- Logic 图：综合中间表示，外观复杂不直接等于 FPGA 资源更多。
- Xilinx 图与资源表：技术映射结果；比较多种写法应使用同一题目、同一接口和本人真实提交。

仓库不保存 Cookie、CSRF token、HAR、账号数据、个人提交源码或个人 OJ 截图。
