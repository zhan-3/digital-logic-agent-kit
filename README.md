# HDL Agent Starter Kit

这是供使用 Agent 的同学独立开展数字逻辑实验的通用起点，**不包含任何人的作业答案、实验报告、波形、OJ 记录或课程网站镜像**。

## 使用方式

1. 将 `PROMPT.md` 发给自己的 Agent，并提供自己有权访问的课程任务要求、目标器件和开发板资料。
2. 从 `templates/` 复制空白 RTL/Testbench 框架，自己确定端口与测试场景。
3. 在本机按 `CHECKLIST.md` 完成自检、Vivado 验证和真实上板。
4. 只使用本人生成的波形、schematic、实测现象撰写报告。

`scripts/run-iverilog.ps1` 是可选的通用编译/仿真入口；它不能代替课程指定的 Vivado 流程。模板文件为 `.txt`，应按实际任务改名、填好接口后再编译。

本仓库没有提供课程网站内容。请自行查阅教师发布的最新版要求。
